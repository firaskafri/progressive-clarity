# Progressive Clarity

Progressive Clarity is a prompt-only writing skill for direct, qualified
answers, natural follow-ups, compact decisions, and useful depth. It guides
Claude to put the answer and any important boundary first, then add context only
when it helps.

After adding the plugin, invoke the Progressive Clarity skill or ask Claude a
question where response structure matters. The skill is advisory: it does not
guarantee accuracy, activation, or consistent behavior.

The plugin contains no executable components, hooks, MCP servers, or network
integrations. It does not independently read, send, or retain personal data.
Claude processes the conversation under the terms and settings of the host
product.

Progressive Clarity is maintained by Firas Kafri. Documentation, privacy
information, terms, and support are available at
https://firaskafri.com/progressive-clarity/.
